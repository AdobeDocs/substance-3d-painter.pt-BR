# Adicionar caminhos de recursos editando as preferências manualmente

É possível adicionar caminhos personalizados adicionais para Prateleira ou Ativos sem abrir o aplicativo.

Para fazer isso, é necessário editar as preferências do aplicativo (que são armazenadas de forma diferente por plataforma). Depois de adicionada, a nova prateleira deve aparecer na lista de prateleiras nas preferências principais. Consulte esta página para obter mais detalhes: [Configuração de Bibliotecas](../../../interface/settings/libraries-configuration.md)

>[!NOTE]
>
> Não há suporte para caminhos de rede. Use um caminho montado para evitar problemas. Consulte: [Carregando arquivos de uma rede](../../../technical-support/workflow-issues/project-issues/loading-files-from-a-network.md).
