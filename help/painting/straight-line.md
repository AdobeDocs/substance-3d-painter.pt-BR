# Linha reta

![](../assets/straight-line.png)

A Linha reta é uma maneira fácil de desenhar uma linha com qualquer ferramenta de pintura com menos cliques e mais precisão.

É uma modificação que é aplicada temporariamente com a ajuda de um atalho de teclado.

A posição de linha reta é calculada a partir da viewport, o que significa que, se entre pinceladas a câmera for movida, a próxima linha reta poderá ser posicionada incorretamente.

## Ativando Linha Reta

Basta pressionar “Shift” no teclado quando uma ferramenta de pintura estiver selecionada para mostrar as linhas pontilhadas indicando o caminho que a ferramenta de pintura seguirá. Quando “Shift” estiver sendo pressionado, clicar em qualquer lugar desenhará a linha.

![](../assets/straight-line-optim.gif){width="400px"}

## Encaixe em linha reta

Além de “Shift” é possível pressionar “Ctrl” também para ajustar a linha reta a cada 5 graus.

![](../assets/straight-line-snap-optim.gif){width="400px"}
