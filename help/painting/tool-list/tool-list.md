# Lista de ferramentas

Esta página detalha todas as ferramentas de pintura disponíveis e como usá-las.

| *Ferramenta* | *Descrição* |

| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-projection.png" width="100px"/></div> | A [Projeção](projection.md) permite aplicar um material ou textura alinhado ao ponto de vista atual. |
