# Simetria de espelho

A simetria espelhada é uma simetria axial que pode ser habilitada na barra de ferramentas contextual:

![](../../assets/symmetry-mirror.png)

## Usar o manipulador para posicionar o eixo de simetria

Você pode acessar as configurações de exibição de Simetria do <b>botão de configurações de Simetria</b> na barra de ferramentas Contextual na parte superior da exibição 3D. Nas configurações de exibição, você pode ativar e personalizar o manipulador. Arraste as alças do manipulador na visualização 3D para alterar a posição do eixo de simetria.

![](../../assets/MirrorSymmetryManip.png)

## Parâmetros de simetria do espelho

![Uma captura de tela das configurações de simetria do espelho](../../assets/MirrorSymmetry-2.png){width="300px"}

| *Parâmetro* | *Descrição* |
| --- | --- |
| <b>Eixo</b> | Define qual eixo da cena é usado para executar a simetria. |
| <b>Posição do eixo</b> | Define o deslocamento do eixo no projeto. Esse valor pode ser editado com os controles deslizantes ou com o Manipulador (veja acima). |
| <b>Mostrar plano</b> | Se ativada, um plano transparente será visível na viewport para delimitar cada lado da simetria espelhada. |
| <b>Mostrar Interseção</b> | Se habilitada, uma linha será desenhada na malha do visor para delimitar cada lado da simetria espelhada. |
| <b>Mostrar Cursor</b> | Se habilitada, um segundo cursor será mostrado no outro lado da simetria para indicar quando a pintura será executada. |
| <b>Ocultar ao Pintar</b> | Se habilitada, o segundo cursor ficará oculto enquanto a pintura estiver em andamento (até que o botão do mouse seja solto). |
| <b>Tamanho do Manipulador</b> | Controla o tamanho do Manipulador na viewport. |
