# Instalando o editor de partículas

Para criar e editar o comportamento do sistema de partículas, o editor PopcornFX precisa ser usado.\
Baixe o editor de um dos seguintes links: [Espelho 1](http://downloads.popcornfx.com/updates/1.5.5.20787/PopcornFx-Editor_Setup_v1.5.5.20787.exe), [Espelho 2](https://www.dropbox.com/s/z1vwzvk2ywlug4p/PopcornFx-Editor_Setup_v1.5.5.20787.exe?dl=1).

>[!NOTE]
>
> O Painter usa uma versão antiga do editor porque ele precisa do suporte de uma versão específica. Para obter mais informações, consulte também a [wiki oficial](https://wiki.popcornfx.com/).
