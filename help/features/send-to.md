# Enviar para

![Imagem do banner](../assets/sendto_banner.jpg)

<b>Enviar para</b> são ações para exportar e importar facilmente recursos de um projeto para outro aplicativo, evitando a necessidade de fazê-lo manualmente. Enviar para pode ser usado para exportar o modelo 3D e suas texturas para outro aplicativo de renderização ou para receber materiais de Substance do Substance 3D Designer.

As ações Enviar para estão disponíveis por meio do menu <b>Arquivo > Enviar</b> para.

Os <b>Enviar para</b> com suporte no momento são:

* Enviar para o <b>Photoshop</b>
* Enviar para o <b>Substance 3D Stager</b>
* Enviar para o <b>After Effects</b>

A Painter também pode receber recursos de outros aplicativos, como:

* <b>Substance 3D Designer</b>
* <b>Substance 3D Sampler</b>

Para obter mais informações sobre como receber recursos, consulte a [página de documentação dedicada](../content/importing-assets/receiving-assets-from-other-substance-3d-applications.md).

>[!NOTE]
>
> Alguns dos fluxos de trabalho de Enviar para estão disponíveis apenas com a versão de Adobe do Painter devido a dependências técnicas com o software Creative Cloud Desktop.
> 
> Além disso, algumas ações no menu Enviar para poderão não estar disponíveis se o software necessário não estiver instalado.
