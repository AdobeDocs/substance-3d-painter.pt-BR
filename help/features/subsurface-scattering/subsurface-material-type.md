# Tipo de Material de Subsuperfície

Esta página lista os vários tipos de materiais que podem ser criados com o recurso de dispersão da subsuperfície e como configurar o Substance 3D Painter para criá-los. Para cada tipo de material, são fornecidas uma escala e uma cor que podem ser definidas nos [Parâmetros da Subsuperfície](subsurface-parameters.md).

>[!NOTE]
>
> Os valores listados nesta página estão aqui para fornecer uma visão geral de cada tipo de material. Eles não são valores exatos e precisam ser interpretados e/ou ajustados por projeto.

## Pele humana

![](../../assets/mat-skin.jpg)

Para um bom material da pele requer:

* Uma boa textura de base : para um caractere realista, isso significa uma boa quantidade de detalhes e várias cores.
* Uma textura forte de height/normal : o efeito de subsuperfície suavizará os detalhes da superfície, tendo detalhes fortes em primeiro lugar, compensará.

| *Configuração* | *Descrição* |
| --- | --- |
| **Escala** | <ol data-preserve-html="true"><li data-preserve-html="true">05 a 0,2</li></ol> |
| **Cor** | **R** : 0,575 **G** : 0,894 **B** : 0,376 <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/color-skin.png"/></div> **Observação:** esta cor é adequada para o tipo de pele caucasiana. |

Exemplos de humanos realistas podem ser encontrados por meio de varreduras 3D de pessoas reais:

* Emily Digital : <http://gl.ict.usc.edu/Research/DigitalEmily2/>
* Cabeça LPS de Realidades Infinitas : <http://www.ir-ltd.net/> | <http://casual-effects.com/data/>
