# Plug-ins

O Substance 3D Painter tem uma API de script dedicada que permite criar plug-ins personalizados para adicionar funcionalidades e comportamentos personalizados.\
Os plug-ins são escritos em JavaScript e podem ser combinados com a linguagem QML para criar uma interface personalizada dentro do aplicativo. Para obter mais detalhes sobre o que está disponível na API, consulte a documentação de scripts (disponível no menu Ajuda do aplicativo).

## Plug-ins padrão

O Substance 3D Painter tem dois plug-ins padrão que mostram conteúdo diferente.

* [Salvamento automático](autosave.md)
* [Atualizador de recursos](resources-updater.md)
