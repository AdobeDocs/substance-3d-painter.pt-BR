# Florescer

![](../../assets/v12_post_bloom.jpg)

Cria um brilho suave ao redor das áreas brilhantes da cena. Simula como a luz dispersão em uma aura brilhante.

| <b>Parâmetro</b> | <b>Descrição</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Valor</b> | Controla a intensidade do efeito de desabrochar. Valores mais altos produzem um brilho mais pronunciado em torno das áreas claras. |
| <b>Limite</b> | Define o nível mínimo de brilho necessário para acionar o desabrochar. Somente os pixels mais brilhantes do que esse valor terão brilho. Um limite de 1,0 significa que apenas os pixels mais brilhantes do que o branco da tela florescerão. |
| <b>Queda automática</b> | Determina até onde a flor se espalha a partir de áreas claras. Valores mais baixos criam um brilho mais compacto, enquanto valores mais altos espalham o efeito por uma área maior. |
