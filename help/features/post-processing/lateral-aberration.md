# Aberração lateral

![](../../assets/v12_post_aberration.jpg)

Simula o desvio cromático, deslocando os canais de cores para fora do centro da imagem, reproduzindo a dispersão de cores visível nas bordas das lentes reais da câmera.

| <b>Parâmetro</b> | <b>Descrição</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>Valor</b> | Controla a intensidade do efeito de dispersão de cores. Valores mais altos produzem uma separação de canal mais acentuada em direção às bordas. |
| <b>Raio</b> | Controla o tamanho da região central não afetada. Valores menores movem o efeito de desvio para mais perto do centro, afetando mais da imagem. |
| <b>Suavidade</b> | Controla o smoothness da transição entre o centro corrigido e as bordas aberradas. |
| <b>Proporção</b> | Define a proporção da região afetada. Um valor de 1 cria uma forma circular, enquanto valores maiores que 1 criam um padrão elíptico mais largo. |
| <b>Centralizar X</b> | Posição horizontal do centro óptico a partir do qual irradia o desvio. |
| <b>Centro Y</b> | Posição vertical do centro óptico a partir do qual o desvio irradia. |
| <b>Desvios acromáticos</b> | Altera as cores da aberração do arco-íris padrão para tons de verde/violeta. |
