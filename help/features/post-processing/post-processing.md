# Pós-processamento

![](../../assets/v12_banner_post_effects2.jpg)

Os Pós-efeitos são filtros que podem ser aplicados às imagens renderizadas na viewport do Substance 3D Painter para simular efeitos de câmera comuns.

Os pós-efeitos podem ser ativados em qualquer projeto por meio da janela [Configurações de Exibição](../../interface/display-settings/display-settings.md).

>[!NOTE]
>
> Esses pós-efeitos não são aplicados à exibição 2D para conveniência. Somente a exibição 3D mostra o resultado da imagem com os efeitos.

As páginas a seguir descrevem os diversos efeitos de pós-processo atualmente suportados:

* [Profundidade de campo](depth-of-field.md)
* [Florescer](bloom.md)
* [Brilho](glare.md)
* [Reflexo da lente](lens-flare.md)
* [Aberração lateral](lateral-aberration.md)
* [Vinheta](vignette.md)
* [Tornar Nítido](sharpen.md)
* [Foto granulada](film-grain.md)
* [Mapeamento de tons](tone-mapping.md)
* [Correção de cor](color-correction.md)

A tabela de textura de pesquisa também pode ser usada para ajustar o resultado final da imagem. Para obter mais informações, consulte a documentação do [Perfil de cores](color-profile.md).
