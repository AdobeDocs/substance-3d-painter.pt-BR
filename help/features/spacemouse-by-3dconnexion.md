# SpaceMouse® por 3Dconnection

![](../assets/spacemouse-banner.jpg)

SpaceMouse® by 3Dconnection é um dispositivo que permite navegar facilmente em 3D. Pode ser usado para manipular o modelo câmera/3d na janela de visualização do aplicativo.

* O SpaceMouse® é suportado desde a versão 7.4.2.
* Para usar corretamente este dispositivo, instale o driver mais recente de [3Dconnection](https://3dconnexion.com/uk/drivers/).

>[!NOTE]
>
> Usuários que usam o modelo compacto e precisam girar frequentemente o mapa de ambiente podem optar por atribuir a tecla SHIFT ao botão esquerdo.

## Visão geral

O botão de controle principal ou o SpaceMouse® permite girar, deslocar e aplicar zoom na viewport de maneiras que não são possíveis com controles regulares de mouse/caneta e teclado. O dispositivo pode ser usado em combinação com mouse e tablets com caneta.

Todos os modelos e versões devem ser compatíveis com o aplicativo:

| Modelo | Descrição | Visual |
| --- | --- | --- |
| **Modelo Compacto** | Modelo base com o controle Knob. | <div><img class="confluence-embedded-image" data-preserve-html="true" src="../assets/3Dconnexion_SpaceMouse-Wireless-400x400.png" width="200"/></div> |
| **Modelo Pro** | Controle de botão e botões adicionais para atalho de teclado. | <div><img class="confluence-embedded-image" data-preserve-html="true" src="../assets/3Dconnexion_SpaceMouse-Pro-400x400.png" width="200"/></div> |

>[!NOTE]
>
> Os modelos Compact, Pro e Enterprise foram testados e validados para funcionar corretamente com o aplicativo.

## Menu radial

O menu pode ser acessado diretamente do dispositivo:

* No modelo Compacto, clicando no botão esquerdo e escolhendo propriedades no menu radial:

  ![](../assets/image2022-3-3-15-14-41.png){width="250px"}
* Nos modelos Pro e Enterprise, o menu de propriedades pode ser acessado pressionando o botão Menu.

Como alternativa, clique com o botão direito no ícone 3Dconnection na bandeja do sistema (ao lado do relógio do sistema) e escolha **Abrir Configurações 3Dconnection**. Este menu é sensível ao contexto com base na última janela ativa. Sua barra de título indica a qual programa ele corresponde, se não for o Adobe Substance 3D Painter, alterne para a janela do Painter e volte para a janela de configurações:

## Configurações padrão

![](../assets/image2022-3-3-10-23-48.png){width="400px"}

No painel de configurações do SpaceMouse®, as configurações padrão para Painter estão disponíveis na versão mais recente dos drivers. Nenhuma configuração adicional é necessária, basta conectar o dispositivo e ele será plug and play.

Certifique-se de selecionar o dispositivo correto no menu suspenso superior, por padrão deve selecionar o correto.

O controle deslizante “velocidade” altera a sensibilidade em todos os eixos e direções.

### Configurações avançadas

Clicando no botão “Configurações avançadas”, você pode alterar o comportamento detalhado dos controles principais.

Qualquer configuração padrão pode ser modificada. Há duas seções importantes com as guias **Modos de navegação** e **Centro de rotação**.

#### Modos de navegação

![](../assets/image2022-3-3-15-5-18.png){width="400px"}

Defina o comportamento do comportamento do botão em 3D:

| Configuração | Descrição |
| --- | --- |
| Modo de objeto | O botão é o próprio objeto 3D, é o padrão. |
| Modo de câmera | Controle a câmera livremente em 3D. |
| Modo de câmera de destino | Controle a câmera sempre visando um ponto no espaço 3D. |
| Modo Helicóptero | Controle um helicóptero no espaço 3D. |
| Bloquear horizonte | Bloquear a câmera para que o horizonte fique sempre horizontal. O Painter já oferece uma opção semelhante em suas configurações, mas ela pode ser controlada separadamente aqui. Ela está bloqueada por padrão. |

#### Centro de rotação

![](../assets/image2022-3-3-10-25-26.png){width="400px"}

Defina o comportamento do ícone da tabela dinâmica pequena:

| Configuração | Descrição |
| --- | --- |
| Automático | Mova automaticamente o pivô ou o destino da câmera; se estiver desativado, ele sempre se prende ao pivô de origem da malha. |
| Sempre mostrar | O ponto dinâmico é sempre exibido na janela de visualização 3D, mesmo quando não está interagindo com o dispositivo. |
| Mostrar em movimento | O ponto dinâmico é exibido na viewport 3D somente quando se está interagindo com o dispositivo. Essa é a opção padrão. |
| Ocultar | Remova completamente o ponto pivô na viewport 3D. |

>[!NOTE]
>
> O ponto dinâmico foi projetado especificamente para o Painter, mas pode ser ocultado, se necessário.
