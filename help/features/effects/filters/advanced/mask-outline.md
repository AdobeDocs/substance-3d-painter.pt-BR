</td>

## Descrição

O filtro Contorno de máscara cria um contorno a partir das arestas de uma máscara.

É usado em uma camada de textura ou dentro de uma máscara (saída em preto e branco) para gerar um contorno interno, externo ou duplo em torno de uma forma mascarada.

</td>
</tr>

<a name="parameters"></a>

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Posição da máscara:</b> | Selecione se o contorno será exibido fora, dentro ou em ambos os lados da borda da máscara. |
| <b>Começar do Preto:</b> | Se marcada, o contorno começa do preto. Isso age efetivamente como um tipo de alternância de inversão. |
| <b>Limite:</b> | Ajuste o limite usado para detectar a borda da máscara. |
| <b>Largura:</b> | Ajuste a largura do contorno. |
| <b>Desfoque:</b> | Ajuste o desfoque aplicado ao contorno. |
| <b>Forma da curva:</b> | Ajuste a forma da queda do contorno. |
