## Descrição

O filtro Height para normal gera dados normais precisos com base no canal do height.

É usado em uma camada de textura para converter as informações do height em dados normais.

<a name="parameters"></a>

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Substituir Normal Existente:</b> | Alternar a substituição dos dados normais existentes. |
| <b>Usar Unidades Mundiais:</b> | Alternar o uso de unidades mundiais para a conversão. |
| <b>Intensidade Normal:</b> | Se as **Unidades Mundiais** forem **Falsas**, use esta opção para ajustar a intensidade dos dados normais gerados. |
| <b>Tamanho da superfície (cm):</b> | Se as **Unidades Mundiais** forem **Verdadeiras**, use esta opção para ajustar a largura ou o height, o que for maior, da superfície representada. |
| <b>Profundidade de Height (cm):</b> | Se as **Unidades Mundiais** forem **Verdadeiras**, use esta opção para ajustar a faixa máxima de heights da superfície. |
