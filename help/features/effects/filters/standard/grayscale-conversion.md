## Descrição

O filtro de Conversão em escala cinza converte um canal/imagem colorida em tons de cinza, ponderando a luminância de cada canal de cor. Você tem muitas opções para ajustar a conversão.

É usado em uma camada de textura ou camada de máscara para converter os canais em tons de cinza ou para converter uma imagem colorida em tons de cinza e usá-la como máscara.

## Entradas

| Nome de entrada | Descrição |
| --- | --- |
| <b>Entrada personalizada:</b> cor | Use uma textura personalizada ou um ponto de ancoragem. |

<a name="parameters"></a>

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Entrada de canal:</b> | Selecione a entrada de canal usada para a conversão. |
| <b>Inverter:</b> | Alterna a inversão do resultado. |
| <b>Saldo:</b> | Ajuste o equilíbrio do resultado entre preto e branco, semelhante a um ajuste de brilho. |
| <b>Contraste:</b> | Ajuste o contraste/declínio do resultado. |
| <b>Modo:</b> | Selecione o modo de conversão de tons de cinza. |
| <b>Vermelho:</b> | Ajuste a ponderação para o canal Vermelho. Essa ponderação é usada para calcular o resultado da escala de cinza. |
| <b>Verde:</b> | Ajuste a ponderação do canal Verde. Essa ponderação é usada para calcular o resultado da escala de cinza. |
| <b>Azul:</b> | Ajuste a ponderação para o canal Azul. Essa ponderação é usada para calcular o resultado da escala de cinza. |
| <b>Alpha:</b> | Ajuste a ponderação para o canal Alfa. Essa ponderação é usada para calcular o resultado da escala de cinza. |
