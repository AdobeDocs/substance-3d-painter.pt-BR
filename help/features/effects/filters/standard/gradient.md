## Descrição

O filtro Gradiente remapeia os valores de tons de cinza de uma imagem usando um gradiente personalizado.

Pode ser usado para ajustar os valores de uma imagem em tons de cinza ou para colorir a entrada em tons de cinza, mapeando-a para um gradiente personalizado.

</td>
</tr>

<a name="parameters"></a>

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Exibir Gradiente (Depuração):</b> | Alterna a exibição da visualização de depuração do gradiente. |
| <b>Quantidade de cores:</b> | Ajuste o número de cores usadas no gradiente. |
| <b>Cor do Combinar em Linear:</b> | Alternar mesclagem linear de cores. |
| <b>Cor 1:</b> | Selecione a primeira cor. |
| <b>Posição da Cor 1:</b> | Ajuste a posição da primeira cor. |
| <b>Cor 2:</b> | Selecione a segunda cor. |
| <b>Posição da Cor 2:</b> | Ajuste a posição da segunda cor. |
| <b>Cor N:</b> | Selecione a enésima cor. |
| <b>Posição N Da Cor:</b> | Ajuste a posição da enésima cor. |

### Transformação de entrada

| Nome do parâmetro | Descrição |
| --- | --- |
| **Modo de tons de cinza:** | Selecione o modo de transformação de tons de cinza. Você pode escolher entre Redução da saturação, Luma, Média, Máx e Mín. |
| **Intensidade de desfoque:** | Ajuste o quanto a entrada está desfocada. |
| **Saldo:** | Ajuste o equilíbrio da entrada deslocando o ponto médio em direção ao preto ou branco, semelhante a um controle de brilho. |
| **Contraste:** | Ajuste o contraste da entrada. |
| **Inverter:** | Alterna a inversão das cores de entrada. |
