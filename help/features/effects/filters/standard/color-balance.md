## Descrição

O filtro Equilíbrio de cores faz alterações sutis em realces, tons médios e sombras.

É usado em uma camada de preenchimento para fazer ajustes sutis de cor.

## Parâmetros

### Realces

| Nome do parâmetro | Descrição |
| --- | --- |
| **Ciano &lt;-> Vermelho:** | Mude a cor para ciano ou vermelho. |
| **Magenta &lt;-> Verde:** | Mude a cor para magenta ou verde. |
| **Amarelo &lt;-> Azul:** | Mude a cor para amarelo ou azul. |
