## Descrição

O filtro Espelho é um filtro de simetria para copiar uma parte da entrada.

É usado em uma camada de textura (cor) ou uma máscara para espelhar materiais, máscaras, formas completos etc. com base no eixo do espelho.

</td>
</tr>
</table>

>[!NOTE]
>
> O filtro espelhado funciona no espaço UV, portanto, pode ser útil abrir a Visualização 2D no **Viewport**.

<a name="parameters"></a>

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Exibir Depuração:</b> | Alterna a exibição da visualização de depuração. |
| <b>Modo:</b> | Selecione o modo espelhado. |
| <b>Deslocamento X Do Eixo:</b> | Ajuste o deslocamento do eixo X. |
| <b>Deslocamento Y do Eixo:</b> | Ajuste o deslocamento do eixo Y. |
| <b>Inverter Eixo X:</b> | Alterne a inversão no eixo X. |
| <b>Inverter Eixo Y:</b> | Alterne a inversão no eixo Y. |
| <b>Tipo de Canto:</b> | Selecione como os cantos espelhados são tratados. |
