## Descrição

O filtro Pixelização converte uma entrada em blocos grandes para simular uma aparência pixelada.

É usado em uma camada de textura (cor) ou uma máscara para pixelar materiais completos, ruídos, máscaras, formas etc.

</td>
</tr>

<a name="parameters"></a>

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Quantidade de pixels:</b> | Ajuste o número de pixels que têm o efeito colateral de alterar o tamanho do pixel. Mais pixels significa pixels menores. |
| <b>Aplicar ao Alpha:</b> | Se marcada, o filtro também modifica o canal Alfa. |
