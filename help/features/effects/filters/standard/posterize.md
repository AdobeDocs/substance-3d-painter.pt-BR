## Descrição

O filtro Posterizar reduz o número de cores ou tons em uma imagem, criando uma aparência de passo a passo com áreas e bordas mais pronunciadas.

É usado em camadas de textura ou máscaras (coloridas ou em tons de cinza) para criar looks gráficos estilizados simplificando as cores. Isso geralmente é útil para pôsteres, ilustrações ou a redução de detalhes para efeitos artísticos.

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Valor das Cores:</b> | Ajuste o número de etapas de cor. |
| <b>Aplicar ao Alpha:</b> | Se marcada, o canal Alfa também é afetado por este filtro. |
