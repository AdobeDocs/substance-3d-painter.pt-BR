## Descrição

O filtro Percepção de HSL ajusta o matiz, a saturação e a luminosidade.

É usado em uma camada de textura (cor) para fazer ajustes de matiz, saturação e luminosidade.

<a name="parameters"></a>

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Modo:</b> | Selecione o modo de ajuste de HSL. **Perceptiva** ajusta os valores com base em como percebemos a cor, enquanto **Regular** ajusta com base em como o computador representa a cor internamente. |
| <b>Matiz:</b> | Ajuste o matiz. |
| <b>Saturação:</b> | Ajuste a saturação. |
| <b>Luminosidade:</b> | Ajuste a luminosidade. |
