## Descrição

O filtro Transformar é usado para transformar (dimensionar, girar, deslocar) uma camada.

É usado em uma camada de textura ou dentro de uma máscara (saída em preto e branco) para, por exemplo, transformar padrões, formas etc.

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Modo de repetição:</b> | Selecione o modo de repetição. |
| <b>Modo de inversão:</b> | Selecione o modo de inversão. |
| <b>Dimensionamento de X:</b> | Ajuste a escala de X do resultado. |
| <b>Escala de Y:</b> | Ajuste a escala de Y do resultado. |
| <b>Deslocamento X:</b> | Ajuste o deslocamento X do resultado. |
| <b>Deslocamento Y:</b> | Ajuste o deslocamento Y do resultado. |
| <b>Rotação de Bloco Seguro:</b> | Alterne a rotação segura para ladrilhos. |
| <b>Rotação:</b> | Ajuste a rotação. |
| <b>Dimensionamento:</b> | Ajuste a escala geral. |
| <b>Deslocamento:</b> | Ajuste o deslocamento geral. |
