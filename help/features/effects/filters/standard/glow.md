## Descrição

O filtro Brilho cria um brilho externo ao redor das partes visíveis da entrada.

É usado em uma camada de textura ou dentro de uma máscara (saída em preto e branco) para adicionar um brilho suave ou preciso ao redor de formas e materiais.

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Usado em uma Máscara:</b> | Se marcada, o brilho é usado em uma máscara. |
| <b>Modo:</b> | Selecione se o brilho usa o modo Suave ou Preciso. |
| <b>Largura:</b> | Ajuste a largura do brilho. |
| <b>Propagação:</b> | Ajuste a propagação do brilho. |
| <b>Opacidade:</b> | Ajuste a opacidade do brilho. |
| <b>Cor:</b> | Ajuste a cor do brilho. |
