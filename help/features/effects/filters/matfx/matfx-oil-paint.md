## Descrição

O filtro Tinta a óleo MatFX estiliza a origem com uma aparência de tinta a óleo.

É usado em camadas de textura para criar traçados de pintura, variação de cores e detalhes de superfície inspirados na tinta a óleo.

| Nome de entrada | Descrição |
| --- | --- |
| <b>Entrada de imagem:</b> cor | Use a entrada da imagem. |

<a name="parameters"></a>

## Parâmetros

As **predefinições** estão disponíveis e podem atualizar rapidamente vários outros parâmetros no Filtro para agirem como um ponto de partida.

>[!NOTE]
>
> Quando uma predefinição é selecionada, ela define todos os parâmetros com um valor predefinido. Se você fez alterações no filtro que não deseja perder, pode valer a pena criar uma duplicata do filtro e alternar a visibilidade antes de tentar as predefinições.

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Tipo de entrada:</b> | Selecione o tipo de entrada usado pelo efeito. |
| <b>Intensidade do efeito:</b> | Ajuste a intensidade geral do efeito. |
| <b>Detalhes Finos:</b> | Ajuste a quantidade de detalhes finos preservados no resultado. |
| <b>Nitidez:</b> | Ajuste a nitidez do resultado. |
| <b>Aspereza:</b> | Ajuste o valor de aspereza. |
| <b>Variação de aspereza:</b> | Ajuste a variação de aspereza no resultado. |
| <b>Detalhes da aspereza:</b> | Ajuste quantos detalhes afetam a aspereza. |
| <b>Intensidade Normal:</b> | Ajuste a intensidade do efeito normal. |
| <b>Influência de direção do traçado normal:</b> | Ajuste a intensidade com que a direção do traçado afeta o resultado normal. |
