## Descrição

O filtro MatFX Comic Book estiliza materiais com uma aparência inspirada em quadrinhos.

É usado em camadas de textura para criar um estilo de renderização gráfico e ilustrado com sombreamento simplificado e tratamento visual arrojado.

## Entradas

| Nome de entrada | Descrição |
| --- | --- |
| <b>Oclusão de ambiente:</b> tons de cinza | Use o mapa de oclusão de ambiente feito bake. |
| <b>Curvatura:</b> tons de cinza | Use o mapa de curvatura feito bake. |

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |

| <b>Contraste de Entrada:</b> | Ajuste o contraste da entrada. |
| <b>Luminosidade de entrada:</b> | Ajuste a luminosidade da entrada. |

| <b>Tolerância de borda:</b> | Ajuste a tolerância de detecção de borda. |

| <b>Intensidade de Tinta:</b> | Ajuste a intensidade do efeito de tinta. |
| <b>Distorcer:</b> | Ajuste o efeito de distorção. |
| <b>Nitidez:</b> | Ajuste a nitidez do resultado. |

| <b>Luminosidade de saída:</b> | Ajuste a luminosidade da saída. |
