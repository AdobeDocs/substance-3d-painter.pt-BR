## Descrição

O filtro Aquarela MatFX estiliza a origem com uma aparência de aquarela.

É usado em camadas de textura para criar sangramento de aquarela, interação com papel e bordas pintadas de maneira suave.

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Opacidade da Tinta:</b> | Ajuste a opacidade da tinta. |
| <b>Absorção de papel:</b> | Ajuste a intensidade de absorção da tinta pelo papel. |
| <b>Tipo de Acúmulo:</b> | Selecione o método de acumulação. |
| <b>Bordas Espelhadas:</b> | Ajuste a propagação das bordas de tinta. |
| <b>Densidade das Bordas:</b> | Ajuste a densidade das bordas da tinta. |
| <b>Mostrar bordas de tinta cruzada:</b> | Alterna a exibição de bordas de tinta cruzada. |
| <b>Ocultar Papel:</b> | Alterne a visibilidade da textura de papel. |
| <b>Papel Personalizado:</b> | Alternar o uso de uma textura de papel personalizada. |
