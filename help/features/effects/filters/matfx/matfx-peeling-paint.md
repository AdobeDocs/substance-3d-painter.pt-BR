# Tinta de Descascamento do MatFX

## Descrição

O filtro Tinta de Descascamento MatFX cria efeitos de descascamento e descascamento de tinta.

É usado em camadas de textura ou pilhas de materiais para simular tinta de descascamento, revestimentos lascados e expor material subjacente.

</td>
</tr>
</table>

>[!NOTE]
>
> Para expor um material subjacente, use a Tinta MatFX Peeling dentro de um grupo. As camadas fora do grupo e abaixo dele na pilha de camadas serão expostas onde a tinta descascada puxar para longe da superfície.

<a name="parameters"></a>

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Intensidade de desfoque:</b> | Ajuste a intensidade do efeito de desfoque. |
| <b>Quebra automática de linha:</b> | Alternar quebra automática de desfoque. Quando ativado, o efeito obtém amostras de pixels do lado oposto da textura. |
| <b>Nível de Descascamento:</b> | Ajuste o nível geral de descascamento. |
| <b>Distância de Descascamento:</b> | Ajuste o quanto a tinta parece se descascar. |
| <b>Nível de partícula:</b> | Ajuste a quantidade de lascas. |
| <b>Densidade da bolha de ar:</b> | Ajuste a densidade das bolhas de ar. |
| <b>Densidade de oscilação:</b> | Ajuste a densidade da formação de lascas. |
| <b>Valor X em oscilação:</b> | Ajuste a quantidade de lascas ao longo do eixo X. |
| <b>Valor Y em oscilação:</b> | Ajuste a quantidade de lascas ao longo do eixo Y. |
| <b>Usar Curvatura:</b> | Alterna o uso da entrada de curvatura. |
| <b>Distância da curvatura:</b> | Ajuste a distância de amostragem de curvatura. |
| <b>Contraste de curvatura:</b> | Ajuste o contraste da entrada de curvatura. |

### Parâmetros técnicos

Estes parâmetros permitem que você modifique a superfície superior do material descascado.

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Luminosidade:</b> | Ajuste a luminosidade. |
| <b>Contraste:</b> | Ajuste o contraste ou a queda do resultado. |
| <b>Alteração de matiz:</b> | Ajuste a alteração de matiz. |
| <b>Saturação:</b> | Ajuste a saturação. |
| <b>Intensidade Normal:</b> | Ajuste a intensidade normal. |
| <b>Intervalo de Heights:</b> | Ajuste o intervalo de height usado pelo efeito. |
| <b>Posição do Height:</b> | Ajuste a posição do height usada pelo efeito. |
| <b>Intensidade de Oclusão de ambiente:</b> | Ajuste a intensidade da oclusão de ambiente. |
