## Descrição

O filtro MatFinish Rough faz parte de uma coleção de acabamento de metal e é usado para criar um efeito de metal áspero.

É usado em uma camada de preenchimento. Ajuste a cor, a aspereza, o metal e outras propriedades da camada de preenchimento de base e, em seguida, adicione o filtro para o tratamento de superfície final.

<a name="parameters"></a>

## Entradas

| Nome de entrada | Descrição |
| --- | --- |
| <b>Desgaste personalizado:</b> em tons de cinza | Use uma textura de desgaste personalizada ou um ponto de ancoragem. |
| <b>Posição:</b> Cor | Use o mapa de Posição feita bake. |
| <b>Normais do Espaço Mundial:</b> Cor | Use o mapa do World Space Normals feito bake. |

## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| <b>Semente:</b> | Atribua um valor aleatório para criar uma variação diferente sem alterar as configurações gerais. |
| <b>Escala:</b> | Ajuste a escala geral do acabamento. |
| <b>Dimensionar Desgaste:</b> | Ajuste a escala do padrão de desgaste. |
| <b>Intensidade do pincel:</b> | Ajuste a intensidade do efeito de pincel. |
| <b>Distorção de pincel:</b> | Ajuste a quantidade de deformação aplicada ao pincel. |
| <b>Usar Flake Personalizado:</b> | Alternar o uso da entrada personalizada do flake. |
| <b>Mapeamento Triplanar:</b> | Alternar mapeamento triplanar. |
| <b>Usar Desgaste Personalizado:</b> | Alternar o uso de uma textura de desgaste personalizada. |
