# Verificador UV

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>In:</strong> uv, borda, aleatório</td>
    <td style="border: 0;" valign="top"><strong>Descrição</strong><br>O gerador de Verificador UV aplica um padrão de verificador semelhante à grade ao seu modelo para que você possa identificar facilmente problemas UV, como amplificação, escala irregular ou distorção. <br><br>O gerador de Verificador UV geralmente é usado diretamente em uma camada de preenchimento para ver distorções UV.</td>
  </tr>
</table>

## Parâmetros

<table>
  <tr>
    <th>Nome do parâmetro</th>
    <th>Descrição</th>
  </tr>
  <tr>
    <td><strong>Semente</strong></td>
    <td>Defina o valor de propagação usado para gerar a textura do dirt. <br><ul><li>Clique em Aleatório para alternar para outra semente aleatória.</li><li>Clique no lápis para ver o valor de semente atual e insira um valor específico, se desejar.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Modo de Cor do Verificador</strong></td>
    <td>Selecione como as cores são atribuídas:<br><ul><li><strong>Uniforme</strong>: aplica a mesma cor ao conjunto de textura.</li><li><strong>Aleatório</strong>: aplica uma cor aleatória a cada Ilha UV.</li></ul></td>
  </tr>
  <tr>
    <td><strong>Cor do verificador</strong></td>
    <td>Defina a cor do padrão de xadrez.</td>
  </tr>
  <tr>
    <td><strong>Bloco de Grade do Verificador</strong></td>
    <td>Ajuste o tamanho do padrão de xadrez.</td>
  </tr>
  <tr>
    <td><strong>Opacidade da grade do verificador</strong></td>
    <td>Ajuste a opacidade da grade. Com a opacidade 0, somente uma textura de quadriculado é visível, sem uma grade.</td>
  </tr>
  <tr>
    <td><strong>Cor das bordas UV</strong></td>
    <td>Defina a cor das bordas UV.</td>
  </tr>
  <tr>
    <td><strong>Largura das Bordas UV</strong></td>
    <td>Ajuste a largura das bordas UV.</td>
  </tr>
</table>
