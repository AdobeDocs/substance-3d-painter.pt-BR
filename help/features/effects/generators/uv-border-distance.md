# Distância da borda UV

    <td style="border: 0;" valign="top"><strong>Descrição</strong><br>O gerador de Distância de Borda UV cria uma máscara em tons de cinza nas bordas das Ilhas UV, permitindo que você adicione facilmente vários efeitos que seguem as bordas dos UVs.<br><br>O gerador de Distância de Borda UV gera uma textura monocromática (preto e branco). ## Parâmetros

| Nome do parâmetro | Descrição |
| --- | --- |
| **Inverter** | Inverta a saída do gerador. |
| **Saldo** | Ajuste o equilíbrio do efeito, deslocando o ponto médio em direção ao preto ou branco, como um controle de brilho. |
| **Contraste** | Ajuste o contraste/declínio do efeito. |
| **Smoothness** | Ajuste o arredondamento do efeito. Isso é mais visível quando um valor baixo de **Smoothness** é usado. |
| **Distância** | Ajuste o quanto o efeito se estende para longe das bordas UV. |
