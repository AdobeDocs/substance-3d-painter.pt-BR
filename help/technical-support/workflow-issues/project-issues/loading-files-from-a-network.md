# Carregando arquivos de uma rede

O Substance 3D Painter não oferece suporte a caminhos em rede porque isso requer uma **autenticação de conta**, o que o software não pode fazer.\
Portanto, os caminhos devem ser **mapeados** / **montados** pelo sistema operacional.

* **Windows** : <http://www.laptopmag.com/articles/map-network-drive-windows-10>
* **MacOS** : <http://osxdaily.com/2010/09/20/map-a-network-drive-on-a-mac/>
* **Linux** : <http://superuser.com/questions/145191/how-do-i-map-a-drive-network-share-using-the-linux-terminal>
