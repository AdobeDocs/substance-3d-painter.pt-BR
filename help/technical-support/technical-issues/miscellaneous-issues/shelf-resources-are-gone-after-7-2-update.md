# Os recursos de prateleira se foram após a atualização 7.2

Esta página explica por que os recursos podem ter desaparecido e como restaurá-los.

Depois de atualizar para a versão 7.2 (ou mais recente), os recursos personalizados na prateleira, como alfas, filtros, materiais, materiais inteligentes ou até mesmo máscaras inteligentes, podem ter desaparecido. Isso ocorre porque essa nova versão redefiniu as preferências e os arquivos agora estão localizados em uma pasta diferente. Os recursos antigos são ignorados e podem ser restaurados copiando os arquivos manualmente. Para fazer isso, confira o [guia de migração](../../../pipeline-and-integration/resource-management/preferences-and-content-migration.md).
