# Impossível arrastar e soltar arquivos na prateleira

No **Windows 8 e no Windows 10**, se você executar o Substance 3D Painter no modo de administrador, o nível de segurança do software provavelmente será maior do que o nível de segurança do Windows Explorer. Portanto, o Windows não permitirá arrastar e soltar arquivos entre esses aplicativos.

Para corrigir esse problema, você pode:

* Execute o Substance 3D Painter normalmente (sem direitos de administrador).
* Desabilite o UAC (isso **não é recomendado** ).

>[!NOTE]
>
> Também é possível importar recursos simplesmente abrindo a janela de importação:
> 
> 1. Clique no menu “Arquivo”
> 1. Escolha “Importar recursos...”
> 1. Na janela de importação, clique em “Adicionar recursos” para selecionar seus arquivos
