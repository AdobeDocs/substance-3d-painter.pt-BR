# A GPU tem drivers desatualizados

![](../../../assets/driver-outdated.png){width="500px"}

Ao iniciar o Substance 3D Painter, uma janela pop-up pode ser exibida mencionando que os drivers da GPU estão desatualizados. Essa mensagem simplesmente significa que o software requer uma versão mínima dos drivers de GPU para ser instalado. Recomendamos atualizar os drivers de GPU para a versão mais recente disponível quando possível para obter a melhor experiência de trabalho.

| *Fornecedor* | *Link* |
| --- | --- |
| **NVIDIA** | [http://www.nvidia.com/Download/index.aspx](http://www.nvidia.com/Download/index.aspx?lang=en-us) <ul data-preserve-html="true"><li data-preserve-html="true"><strong> GeForce </strong> : versão de SD (Studio Drivers) recomendada.</li><li data-preserve-html="true"><strong> Quadro </strong>: Versão de “Optimal Driver for Enterprise” (ODE) recomendada.</li></ul> |
| **AMD** | <http://support.amd.com/en-us/download> |
| **Intel** | <https://downloadcenter.intel.com/> |

>[!NOTE]
>
> Alguns computadores <b>podem ter duas GPUs</b>: uma integrada (como um chipset Intel) e outra dedicada (como uma placa gráfica Nvidia). <b>Ambos</b> precisam estar <b>atualizados </b>para minimizar o risco de erros no Painter.
