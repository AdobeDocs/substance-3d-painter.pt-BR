# Problemas com GPUs Nvidia em versões recentes do sistema operacional Mac

No Mac OS, o Apple fornece os drivers de GPU validando-os depois de fornecidos pelo construtor da GPU. Desde o Mac OS Mojave, a Apple ainda não validou nenhum driver novo para GPUs recentes da Nvidia. Infelizmente, o Substance 3D Painter precisa de drivers de GPU atualizados para funcionar corretamente.

Para obter mais informações, consulte a seguinte página:

* [Lista de GPUs compatíveis no sistema operacional Mac](https://support.apple.com/en-us/HT208898).
* [Uso de uma GPU externa no sistema operacional Mac](https://support.apple.com/en-us/HT208544).
