# Menu Janela

![](../../assets/window-menu.png)\
O menu janela permite exibir uma lista das janelas e se elas estão visíveis na interface. Você também pode usar o menu da barra de ferramentas para ocultar algumas barras de ferramentas.

| Ação | Descrição |
| --- | --- |
| **Exibições** | Lista as janelas disponíveis na interface (a caixa de seleção indica se ela está visível no momento). |
| **Barras de ferramentas** | Lista as barras de ferramentas disponíveis na interface (a caixa de seleção indica se está visível atualmente, o que permite alterná-las): Docks, Plugins &amp; Tools. |
| **Ocultar interface do usuário** | Oculta todas as janelas e encaixes da interface e maximiza as viewport(s). |
| **Redefinir interface do usuário** | Redefine o layout da janela atual para o padrão. |
