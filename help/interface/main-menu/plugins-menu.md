# Menus de plug-ins JavaScript e Python

![](../../assets/plugins-javascript.png)

Os menus JavaScript e Python listam todos os plug-ins carregados pelo Painter na inicialização. Os plug-ins são separados em dois menus baseados na API de script que estão usando (Javascript ou Python).

Cada plug-in descoberto pelo aplicativo adicionará uma entrada no respectivo menu para acessar as funções adicionais. Nos menus, cada plug-in tem as seguintes opções:

* **desabilitar/habilitar**: ativar ou desativar o plug-in.
* **recarregar**: recarregue o plug-in caso o script tenha sido atualizado enquanto o aplicativo estava em execução.
* **configurar**: se suportado pelo plug-in, exibe a função/janela para configurar o plug-in.
* **sobre**: se suportado pelo plug-in, exibe informações sobre o plug-in.

Para saber mais sobre os plug-ins padrão fornecidos com o Painter ou como criar novos plug-ins por conta própria, consulte a página dedicada [Plug-ins](../../features/plugins/plugins.md).
