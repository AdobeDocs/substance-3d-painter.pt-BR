# Menu Arquivo

![](../../assets/file-menu.png){width="150px"}

O menu Arquivo contém as ações para criar e salvar os projetos, bem como as ações para exportar e importar recursos para um projeto.

| Ação | Descrição |
| --- | --- |
| **Novo** | Abra a janela de criação do novo projeto. Consulte: [Criação de Projeto](../../getting-started/project-creation.md)para obter mais informações. |
| **Abrir** | Abra um arquivo de projeto existente no disco. |
| **Arquivos recentes** | Lista todos os projetos abertos recentemente. |
| **Abrir amostra** | Abra um dos projetos de amostra fornecidos com o aplicativo. |
| **Fechar** | Fecha o projeto aberto no momento. |
| **Salvar** | Salva o projeto atual no local. |
| **Salvar e compactar** | Salve o projeto atual no local e compacte-o (reduza o espaço no disco). |
| **Salvar como** | Salva o projeto atual com um novo nome e localização. |
| **Salvar como cópia** | Salve o projeto atual com um novo nome e local como uma cópia e mantenha o projeto atual aberto. |
| **Salvar como modelo** | Salve as configurações do projeto atual em um arquivo de modelo que possa ser usado para um novo projeto. |
| **Limpar** | Remova quaisquer recursos não utilizados do projeto atual (entrará em vigor após o próximo **Salvamento**). |
| **Importar recursos** | Abra a janela de recursos de importação. |
| **Exportar malha** | Abra a janela de exportação em malha que permite exportar o projeto atual como um arquivo de modelo 3D. |
| **Exportar texturas** | Abra a janela de exportação de textura que permite exportar o projeto atual como texturas de bitmap. |
| **Enviar para** | Liste todas as ações de **Enviar para** para enviar um projeto para outro aplicativo. |
| **Sair** | Feche o aplicativo. Se o projeto atual tiver alterações não salvas, ele exibirá uma mensagem. |

>[!NOTE]
>
> O salvamento de um projeto pode ser feito de duas maneiras:
> 
> * **Incremental** : método padrão, usado ao fazer um salvamento regular. Somente as informações alteradas serão atualizadas no arquivo de projeto no disco. Esse método permite salvar o projeto muito rapidamente sem ter que regravar o arquivo de projeto completamente.
> * **Completo/Compacto**: se uma operação Limpar for executada ou se o projeto for salvo com a ação “Salvar e Compactar”, o método regravará o projeto no disco. Esse método permite eliminar a fragmentação do projeto e reduzir o espaço ocupado. Consulte: [Os projetos são realmente grandes](../../technical-support/workflow-issues/project-issues/projects-are-really-big.md).
