# Atalhos

![](../../assets/settings-shortcuts.png){width="400px"}

Esta página lista todos os atalhos de teclado e mouse disponíveis.

## Visão geral de atalhos

Para obter uma visão geral rápida de todos os Atalhos disponíveis, dê uma olhada no gráfico [disponível em nossos tutoriais](https://helpx.adobe.com/substance-3d/unlisted/tutorials/courses/substance-3d-painter-keyboard-shortcuts.html) .

## Como alterar um atalho

![](../../assets/shortcut-edit.gif)Clique no ícone de “caneta” ao lado de um atalho para editá-lo e inserir a nova combinação.Pressionar a última tecla sairá automaticamente do modo de edição e alterará o atalho.

## Lista de atalhos não editáveis

Alguns atalhos podem **funcionar** apenas se o **mouse estiver sobre** a janela específica.

Exemplo: **copiar** e **colar** requer que o mouse esteja **sobre a pilha de camadas**.

| *Ação* | *Atalho (Windows)* | *Atalho (MacOS)* | Descrição |
| --- | --- | --- | --- |
| **Copiar camada** | Ctrl+C | ⌘+C | Copiar a(s) camada(s) selecionada(s) no momento. |
| **Cortar camada** | Ctrl+X | ⌘+X | Recorta a( s) camada( s) atualmente selecionada( s). |
| **Colar camada** | Ctrl+V | ⌘+V | Cole a camada na(s) memória(s). |
| **Excluir camada** | Excluir | Excluir | Exclui a(s) camada(s) atualmente selecionada(s). |
| **Duplicar camada** | Ctrl+D | ⌘+D | Duplica as camadas atualmente selecionadas. |
| **Agrupar camada** | Ctrl+G | ⌘+G | Coloca as camadas atualmente selecionadas em uma pasta. |
| **Copiar conteúdo da camada** | Ctrl+Shift+C | Option+⌘+C | Copie o conteúdo da camada (pintura) e seus efeitos. |
| **Colar conteúdo da camada** | Ctrl+Shift+V | Option+⌘+V | Cole o conteúdo (pintura) e os efeitos atualmente na memória. |
| **Exibir máscara no visor** | Alt+Mouse para a esquerda | Option+Mouse para a esquerda | Alterna o modo de exibição do visor para a máscara da camada especificada. |
| **Desabilitar/Habilitar máscara** | Shift+Mouse para a esquerda | Shift+Mouse para a esquerda | Alterna o estado da máscara em uma camada. |
|  |  |  |  |
| **Arrastar e soltar material** | CTRL+Arrastar e Soltar | ⌘+Arrastar e Soltar | Pressione e mantenha pressionada esta tecla enquanto arrasta e solta um material (ou material inteligente) na viewport para afetar apenas uma parte específica do modelo 3D. |
|  |  |  |  |
| **Restrição/ajuste do manipulador** | Shift | Shift | Ajuste a transformação ao ajustar o manipulador (translação ou rotação) na Visualização 3D. Restringir proporção ao ajustar o manipulador na Visualização 2D. |
| **Transformação espelhada do manipulador** | Ctrl | ⌘ | O manipulador de espelho aponta a transformação ao redor de seu ponto pivô na Visualização 2D. |
