# Atualizar verificador

![](../../assets/update-cc.png)

Você pode verificar por atualizações do Substance 3D Painter no Creative Cloud Desktop. Navegue até a guia Aplicativos e veja a seção Aplicativos instalados. **Atualização disponível** aparecerá sob o nome do aplicativo se uma atualização estiver pronta para download.

Você pode acessar as notas de versão da versão atual abrindo o Painter e usando a **Ajuda > Notas de versão**.
