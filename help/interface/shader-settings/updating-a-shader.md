# Atualizando um sombreador

Às vezes, pode ser necessário atualizar o sombreador usado por um projeto para corrigir problemas ou aproveitar os recursos mais recentes. Esta página descreve como fazer isso.

Veja a seguir o método passo a passo para atualizar o sombreador de um projeto:

* **Atualizar um Sombreador pela Janela de Sombreador**
* **Atualizar um Sombreador por meio do plug-in Resource Updater**

Se um projeto usar um **sombreador personalizado** (não enviado por padrão com o Substance 3D Painter), consulte a página [Sombreador personalizado](https://substance3d.adobe.com/display/DRAFTPAINTER/Shader+API) para obter um guia sobre como atualizá-lo.

## Atualizar um Sombreador pela Janela Sombreador

### 1 - Abra a janela Configurações de Sombreador

A janela **Configurações de Sombreador** está disponível à direita por padrão na barra de ferramentas do Dock.

![](../../assets/shader-settings-window.png)

### 2 - Clique no botão sombreador e selecione o sombreador atualizado

Clique no botão sombreador (abaixo do botão Desfazer/Refazer) e localize o sombreador que corresponde ao que já foi usado.

![](../../assets/shader-mini-shelf.png)

### 3 - O Sombreador foi atualizado

Depois que o novo sombreador for carregado, a menção **desatualizado** deverá ser removida e o modelo 3D deverá aparecer normalmente no visor.

![](../../assets/updated-shader.png)

## Atualizar um Sombreador por meio do plug-in Atualizador de recursos

### 1 - Abrir o atualizador de recursos

Vá para a esquerda da interface para encontrar a **barra de ferramentas Plug-ins** e clique no ícone do **Atualizador de Recursos**.

![](../../assets/resource-icon.png)

### 2 - Mude para a guia Sombreador

Na nova janela exibida, clique na guia “Sombreador” para exibir o sombreador presente no projeto atual.

![](../../assets/shader-tab.png)

### 3 - Localizar o Sombreador e atualizá-lo

Na guia Sombreador deve aparecer uma lista de todos os recursos de Sombreador do usuário pelo projeto atual. Os Sombreadores **desatualizados** são visíveis com um **plano de fundo vermelho**. Clique no botão “atualizar” ao lado de um recurso para atualizá-lo.

![](../../assets/update-shader-click.gif)
