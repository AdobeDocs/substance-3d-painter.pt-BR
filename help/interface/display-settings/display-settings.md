# Configurações do visor

![](../../assets/display-settings-2.png){width="320px"}

A janela **Configurações de Exibição** reagrupa as configurações de ambiente, câmera e visor. Essas configurações são globais para o projeto e podem afetar a aparência da viewport.

## Modo de visualização

![](../../assets/viewmode.png)

O modo de visualização controla a aparência da viewport. O menu suspenso é dividido em três seções:

| Seção | Descrição |
| --- | --- |
| **Iluminação** | Exiba o modelo 3D na viewport com iluminação total, incluindo sombras, se ativadas. |
| **Canal único** | Também chamado de modo solo. Exiba a malha no visor com apenas um canal ou textura específica, sem iluminação. |
| **Mapas de malha** | Exiba a malha no visor somente com uma textura assada específica sem iluminação. |

>[!NOTE]
>
> O modo de exibição também pode ser alterado com o uso do <b>menu suspenso</b> disponível nos cantos das [viewports](../../interface/viewport/viewport.md). Também há [atalhos](../settings/shortcuts.md) disponíveis para alternar rapidamente entre canais, mapas de malha e até mesmo voltar para o modo de material.
