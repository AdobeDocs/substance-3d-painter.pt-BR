# Modelos de saída padrão

Abaixo há uma lista de Modelos de saída adicionais fornecidos por padrão.  Os Modelos de saída padrão podem ser copiados e modificados na <b>guia Modelos de saída </b>da <b>janela Exportar</b>.

>[!NOTE]
>
> Alguns outros softwares não listados aqui também podem ter suporte (como o **Octano**). Para obter mais informações, consulte o [ecossistema e plug-ins](https://experienceleague.adobe.com/pt-br/docs/substance-3d/ecosystem/home).

| *Predefinição* | *Descrição* |
| --- | --- |
| <b> Lumberyard Amazon </b> | Nomeie e empacote texturas a serem importadas e usadas no Amazon Lumberyard. |
| <b> Arnold (AiStandard) </b> | Predefinição para Arnold (sombreador AiStandard). |
| <b> Arnold UDIM Legacy (AiStandard)</b> | Predefinição para Arnold UDIM Legacy (AiStandard). |
| <b>Mesclador (BSDF de Princípio)</b> | Predefinição para mesclador (BSDF em princípios). |
| <b> Corona </b> | Predefinição para o renderizador Corona. |
| <b> CryEngine 3 </b> | Nomear e empacotar texturas a serem importadas e usadas no Cry Engine 3. |
| <b> Dota 2 </b> | Predefinição para o jogo Dota 2 (pode ser usado com o modelo associado). |
| <b> Tecla </b> | Predefinição para renderizador de captura de tecla. |
| <b>Keyshot 9+</b> | Predefinição para renderizador de captura de chave a partir da versão 9. |
| <b> Lens Studio </b> | Predefinição do Lens Studio (para criar ativos para o Snapchat). |
| <b>Maxwell (Aspereza Metálica)</b> | Predefinição do renderizador Maxwell usando o fluxo de trabalho Aspereza metálica. |
| <b>Maxwell (Textura reluzente de Specular)</b> | Predefinição para o renderizador Maxwell usando o fluxo de trabalho Textura reluzente do Specular. |
| <b> Mapas de Malha </b> | Exporte os slots de mapa de malha cozida de um conjunto de textura individualmente (exportado na mesma resolução do conjunto de textura). |
| <b>Textura reluzente de Specular não PBR</b> | Nomeie e exporte texturas para um fluxo de trabalho Brilho de Specular não PBR. |
| Aspereza metálica de <b> PBR</b> | Nomeie e exporte as texturas necessárias para um fluxo de trabalho regular de PBR metálico/aspereza. |
| Aspereza Metálica de PBR <b> (Grupos de Pastas ou PSD) </b> | Semelhante ao PBR MetalRough, mas cria uma pasta adicional. Esta predefinição é mais adequada para ser usada com o formato de arquivo PSD. |
| <b> Brilho de Specular PBR</b> | Nomeie e exporte as texturas necessárias para um fluxo de trabalho de PBR normal de Specular/textura reluzente. (As texturas são convertidas do fluxo de trabalho BaseColor/Metallic). |
| Brilho de Specular de <b> PBR (convertido de Aspereza metálica</b> | Converta os canais Basecolor, Metallic e Roughness para serem compatíveis com o fluxo de trabalho Specular/brilho. |
| <b> Redshift </b> | Predefinição para renderizador Redshift. |
| <b>Renderman (pxrDisney)</b> | Predefinição para Renderman usando mapas Metálicos e de Aspereza. |
| <b>Renderman (pxrSurface)</b> | Predefinição para Renderman usando os mapas de difusão e de Specular. |
| <b>Roblox (MaterialVariant)</b> | Predefinição para Roblox usando Albedo sem suporte a alfa. |
| <b>Roblox (SurfaceAppearance)</b> | Predefinição para Roblox usando Colormap com canal alfa. |
| <b> Sombra 3D </b> | Predefinição para Shade 3D. |
| <b>Spark AR Studio</b> | Predefinição do Spark AR Studio. |
| <b>Pipeline de Renderização HD do Unity (Padrão Metálico)</b> | Predefinição para o pipeline de renderização em HD do Unity usando mapas Metálicos e de Textura reluzente. |
| <b>Pipeline de Renderização HD do Unity (Specular)</b> | Predefinição para o pipeline de renderização em HD do Unity com o mapa de specular adicionado. |
| <b>Pipeline de Renderização Universal do Unity (Padrão Metálico)</b> | Predefinição para o pipeline de renderização universal do Unity usando mapas metálicos e de Smoothness. |
| <b>Pipeline de Renderização Universal do Unity (Specular)</b> | Predefinição para o pipeline de renderização universal do Unity com mapas de Specular e Smoothness. |
| <b> Mecanismo Irreal (Empacotado) </b> | Nomeie e empacote texturas a serem usadas no Unreal Engine com o menor espaço de memória possível. |
| <b>SSS do Mecanismo Irreal (Empacotado)</b> | Nomeie e empacote texturas a serem usadas no Unreal Engine com o menor espaço de memória possível, substituindo o mapa de opacidade por dispersão subsuperficial. |
| <b> Variar Próximo (Aspereza Metálica)</b> | Predefinição para renderizador Vray usando o fluxo de trabalho PBR. |
| <b>Variar Próxima (Textura Reluzente do Specular)</b> | Predefinição para renderizador Vray usando fluxo de trabalho não PBR. |
| <b> Variar UDIM Herdado (Aspereza Metálica)</b> | Predefinição para renderizador Vray (convenção de nomenclatura UDIM). |
